# embedded-linux-camera-platform
Embedded Linux Camera Platform – Yocto / ARM64

Embedded Linux Camera Platform

A hands-on Embedded Linux project demonstrating Yocto-based ARM64 image construction, Linux system integration, camera/V4L2 pipeline development, and multimedia application deployment.

## Project Status

### Completed
- Yocto-based ARM64 image build
- QEMU ARM64 Linux boot
- Linux kernel and system verification
- Initial V4L2 camera device query application

### In Progress
- Custom Yocto layer
- Camera/V4L2 capture pipeline
- Multimedia integration
- AI inference pipeline
